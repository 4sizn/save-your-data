설정 → 앱 → Safari → 확장 프로그램 → 알뜰 데이터

바로 보여 줄 크기

이 크기보다 작은 사진·동영상은 바로 보여 줘요. 더 크거나 크기를 모르면 불러오기 버튼으로 바뀌어요. 0으로 두면 항상 버튼으로 보여 줘요.

참고: 네이버 기사 사진 1장이 약 30KB예요. 크기는 사이트가 알려 준 실제 크기만 써요. 크기를 모른다고 자주 나오면 위의 모든 웹사이트를 허용으로 바꿔 보세요.

더 아끼고 싶다면: 글만

Safari에서 가 메뉴 → 알뜰 데이터 → 글만을 고르면 글만 받아요. 뉴스 기사 1개가 약 50KB예요. 같은 기사를 그냥 보면 7~46MB였어요.

대신 페이지 모양이 꾸밈없이 보이고 댓글·로그인 같은 기능은 멈춰요. 빈 화면이 나오는 사이트는 그 사이트만 절약으로 바꿔 주세요.

깔끔하게 읽으려면 자주 보는 사이트에서 가 메뉴 → ⋯ → 자동으로 읽기 도구 사용을 켜 두세요. 다음부터 기사만 보기 좋게 열려요.

모드별로 얼마나 아끼나요?

Safari에서 가 메뉴 → 알뜰 데이터에서 모드를 골라요. 원본 페이지 대비 실제로 측정한 값이에요.

절약강력글만
네이버 뉴스44%71%99%
다음 뉴스82%85%99.8%
나무위키42%48%93%
유튜브74%92%74%*

* 유튜브는 글만으로 볼 수 없어서 절약으로 바뀌어요. 처음 방문 기준이라, 다시 방문하면 사이트가 저장해 둔 파일 덕분에 더 적게 써요.

글은 그대로 보여요

글, 링크, 버튼은 막지 않아요. 보고 있는 페이지 내용은 휴대폰 밖으로 보내지 않아요.
